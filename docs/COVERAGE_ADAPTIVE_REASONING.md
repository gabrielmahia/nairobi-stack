## Core rule

> **A correct ranking inside an incomplete universe is still a failed answer.**

The original failure was not that `Spooks / MI-5` was ranked badly. It was that the retrieval frame made an important candidate structurally unlikely to appear at all.

The repair is not exhaustive search. It is **materiality-gated orthogonal search**.

## Compact operating loop

For consequential research, recommendation, investigation, analogy search, forecasting, opportunity discovery, or canon building:

### 1. FRAME
State the actual decision/question, unit of analysis, time horizon, what would materially change the answer, and the cheapest plausible falsifier.

### 2. GENERATE BEFORE RANKING
Do not rank the first candidate set. Generate the universe through the **minimum useful set of independent retrieval routes** selected for the problem.

Candidate routes:
- **SEMANTIC / FUNCTIONAL** — mechanism, function, constraint, not only matching words.
- **GENEALOGICAL** — predecessors, successors, bibliographies, citations, intellectual/institutional ancestry.
- **TAXONOMIC** — enumerate the category before picking examples.
- **TEMPORAL** — old / middle / current eras.
- **GEOGRAPHIC / LANGUAGE** — non-dominant regions, languages, local terminology.
- **FORMAT / SOURCE-CLASS** — papers, registries, courts, patents, code, archives, local reporting, frontline knowledge.
- **ALIAS / ENTITY / CONTROL** — alternate names, transliterations, rebrands, subsidiaries, proxies, relatives, legal identity vs operational control vs economic benefit.
- **ADVERSARIAL / NULL / FAILURE** — counterexamples, benign look-alikes, failure cases, manipulated categories.
- **NEGATIVE SPACE** — what canonical item, predicted trace, or evidence class should be present but is missing?

Do not run all routes mechanically. Use the smallest set whose omission could plausibly change the decision.

### 3. COVERAGE CRITIC
Before closure ask:

> **What kind of correct answer would the present search method be structurally incapable of finding?**

and

> **What am I not even asking—and what would my present way of looking make impossible to see?**

Treat ontology itself as potentially gameable.

### 4. GROUND / PROVENANCE
For material claims preserve:
OBSERVATION → SOURCE → TRANSFORMATION → INFERENCE → HYPOTHESIS.

Check source independence. Ten articles copying one report are one source family, not ten confirmations.

Check denominator/base rate where relevant.

### 5. RIVALS
Maintain at least:
- leading explanation,
- credible competing explanation,
- null / simpler explanation.

Ask what each uniquely predicts and what predicted evidence is missing.

### 6. CAUSALITY / INVERSION
Do not promote association into cause, control, sponsorship, intent, or mechanism without the bridging evidence.

Ask:
> If the leading explanation were false, what should we observe?

### 7. CONFIDENCE IN TWO DIMENSIONS
Report separately when material:

- **ANSWER CONFIDENCE** — strength of evidence for the conclusion.
- **COVERAGE CONFIDENCE** — confidence that the relevant universe/evidence classes were actually searched.

Low coverage means “nothing found” is not evidence of absence.

### 8. STOP
Stop when additional **independent** retrieval routes no longer materially change:
- the candidate universe,
- the leading/rival hypotheses,
- the decision,
- or the next discriminating test.

Coverage is a stopping problem, not a demand for infinite search.

### 9. MISS → SENSOR REDESIGN
When an important omission is discovered:
1. identify the failure class — framing, alias, geography/language, source, format, taxonomy, genealogy, entity resolution, causal model, measurement, or stopping;
2. repair the retrieval architecture;
3. re-run the affected search;
4. propagate the lesson to the canonical instruction layer.

Do **not** fix a systemic miss by merely appending the omitted example.

## Analogy rule

Search analogies by shared:
- mechanism,
- institutional function,
- constraint,
- causal structure,
- genealogy,
- and useful contrast.

Surface resemblance is hypothesis generation, not proof.

Every serious analogy states where it breaks and what new prediction it generates.

## Adversarial ontology rule

For sophisticated actors and fragmented systems, assume labels may hide rather than reveal reality.

Explicitly separate:
- legal identity,
- operational control,
- economic benefit,
- formal role,
- actual function.

Search alternate jurisdictions, intermediaries, related entities, and schema categories where material.

## Efficiency rule

Scale rigor to consequence.

- **Low stakes:** answer directly.
- **Moderate stakes:** 2–3 orthogonal retrieval routes + one rival.
- **High stakes:** fuller universe/coverage audit, provenance, rivals, causal/inversion tests, explicit answer/coverage confidence.
- **Systemic/repeated miss:** run MISS → SENSOR REDESIGN and update the canonical method.

The goal is **minimum systematic blindness**, not imagined omniscience.
