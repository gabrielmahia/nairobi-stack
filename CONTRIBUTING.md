# Contributing to nairobi-stack

This is a community knowledge base. Contributions welcome.

## What's welcome
- Corrections to outdated API information
- New sections (Tanzania, Uganda, Rwanda, Ethiopia contexts)
- Better code examples
- Additions to the USSD patterns guide
- Links to new open data sources

## What's not
- Promotional content for specific providers without balanced comparison
- Content that requires users to sign up or pay for access

## Process
1. Open an issue to discuss significant additions
2. Fork, edit, PR
3. For factual corrections: PR directly, no issue needed

## Style
- First-person "we" or direct second-person "you" — not academic passive
- Concrete examples over abstract descriptions
- Acknowledge when something is "best practice in 2024" vs permanent truth
